How it works
  1. Add or change things on the tabs below.
  2. Press Download data.json at the bottom. For a reading PDF, also upload the PDF into the reading folder on GitHub.
  3. On GitHub, open data.json, replace it with the downloaded file (Add file > Upload files) and press Commit changes. The site updates in about a minute.
This page only prepares a file. It cannot change your live website by itself.
